# Design System — Customer Onboarding Web

## Purpose

This document defines the UI/UX guidelines for the Customer Onboarding frontend.

The goal is to create a clean, modern, professional banking-style interface.

---

## Design Principles

- Clean and minimal
- High readability
- Clear hierarchy
- Consistent spacing
- Professional (banking internal system style)

---

## Layout

- Desktop-first
- Centered content with max width
- Use cards to group sections
- Vertical spacing between sections

---

## Color Palette

Primary:
- Blue (main actions)

Neutral:
- Gray scale for backgrounds and text

Status colors:
- Success → Green
- Warning → Yellow
- Error → Red
- Info → Blue

---

## Typography

- Sans-serif font
- Clear hierarchy:

Headings:
- Large, bold

Body:
- Medium size

Labels:
- Small, muted

---

## Components

### Inputs
- Rounded corners
- Clear borders
- Focus state with highlight

### Buttons
- Primary (blue)
- Secondary (outlined)
- Disabled state

### Cards
- Rounded corners
- Light shadow
- Padding inside

### Tables
- Clean rows
- Hover effect
- Clear column separation

---

## Dark Mode

- Background: dark gray
- Cards: slightly lighter
- Text: high contrast
- Maintain same color logic

---

## Pages

### 1. Onboarding Creation

- Form divided into sections:
  - Customer data
  - Contact
  - Address

- Dynamic lists:
  - Emails
  - Phones

- Submit button at bottom

---

### 2. Onboarding List

- Filters on top
- Table with pagination
- Status badges with colors

---

### 3. Onboarding Detail

- Sections:
  - Customer data
  - Contacts
  - Addresses
  - Documents
  - Audit logs

- Document upload area

---

## UX Behavior

- Show loading states on actions
- Show clear validation errors
- Disable submit while loading
- Feedback after actions (success/error)

---

## Accessibility

- Good contrast
- Labels for all inputs
- Keyboard-friendly navigation

---

## Tone

- Professional
- Neutral
- Clear
- No playful or casual UI

---

## Goal

Deliver a UI that looks like a real banking internal system, clean and production-ready.
